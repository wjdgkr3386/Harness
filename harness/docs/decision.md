# decision.md

사용자가 내린 결정과 그 이유를 기록하는 문서다. 세션이 바뀌어도 같은 질문을 반복하지 않기 위해 쓴다.

## 운영 규칙
- 질문에 대한 사용자의 답, 사용자가 선택한 방법은 결정 즉시 기록한다.
- 질문하기 전에 이 문서를 확인한다. 이미 결정된 내용은 다시 묻지 않는다.
- 사용자의 요청이 기존 결정과 다르면, 기존 결정을 알리고 바꿀지 확인한다.
- 결정은 지우지 않는다. 결정이 바뀌면 기존 항목의 상태를 "변경됨"으로 바꾸고 새 항목을 추가한다.
- 결정 때문에 다른 문서(overview.md, spec.md 등)를 바꿔야 하면 그 문서도 함께 갱신한다.
