현재 보고 있는 README.md 파일은 사람이 보기 위해 만든 파일이다.

하네스 엔지니어링을 사용하여 프로젝트를 진행하도록 만든 하네스 공통 규칙 모음이다.

아래 파일들은 AI가 보기 위해 만든 파일들이다.
- harness/CLAUDE.md : AI가 지켜야할 전반적인 규칙을 정의해둔 파일이며, 누구라도 어떤 상황이든 변경할 수 없고 유지되어야 한다. (사용자 or AI)
- harness/docs/database.md : 데이터베이스를 정의해둔 파일
- harness/docs/screen.md : 화면 설계 템플릿 (수정하지 않고, 화면 파일마다 같은 경로에 `{화면파일명}_screen.md`로 복사해서 사용)
- harness/docs/spec.md : 기술스택을 정의해둔 파일
- harness/docs/test.md : 테스트 내용을 정의해둔 파일
- harness/docs/todo.md : 작업하면서 진행 내용을 기록할 파일
- harness/docs/guide.md : 파일 경로를 지정하고 안내하는 파일
- harness/docs/coding_rule.md : 코딩 규칙(네이밍, 코드 작성 원칙, 파일 크기)을 정의해둔 파일
- harness/docs/structure.md : 폴더 구조와 간단한 설명을 정리한 파일
- harness/docs/loop.md : 작업 진행 순서와 종료 조건을 정의해둔 파일

# 사용 방법
1. 프로젝트를 진행할 폴더를 생성한다.
2. harness 폴더 내에 있는 docs 폴더와 CLAUDE.md 파일을 복사하여 프로젝트 폴더 안에 붙여넣는다.
3. Claude Code의 자동 압축을 끈다. (아래 "자동 압축 끄기" 참고)
4. 프로젝트 폴더를 작업 폴더로 지정해 Claude Code를 실행한다. (CLAUDE.md는 자동으로 읽힌다)

## 작업 흐름과 사용자 확인 시점
AI는 docs/loop.md 순서(계획 → 승인 → 구현 → 검증 → 완료)로 작업한다.

아래 시점에는 AI가 멈추고 사용자의 답을 기다린다.

| 시점 | AI가 하는 일 | 사용자가 할 일 |
|---|---|---|
| 작업 계획 후 | 계획(목표, 완료 조건)을 보여준다 | 승인 또는 수정 요청 |
| 화면 설계 후 | `{화면파일명}_screen.md` 내용을 보여준다 | 승인 또는 수정 요청 |
| 화면 완성 후 | 기능 없이 만든 화면을 보여준다 | 확인 또는 수정 요청 |
| 같은 검증이 3번 연속 실패 | 실패 내용을 보고하고 질문한다 | 해결 방법 결정 |
| 내용이 애매할 때 | 질문한다 | 답변 |
| 남은 컨텍스트 부족 | todo.md를 정리하고 멈춘다 | 새 세션 시작 |
| 작업 완료 후 | 결과를 보고하고 다음 작업 계획을 보여준다. 백로그가 비어 있으면 다음 작업을 묻는다 | 승인 또는 다른 작업 지시 |

## 남은 컨텍스트 확인하기
- Claude 데스크톱 앱에서는 AI가 직접 컨텍스트 사용량을 확인한다.
- 터미널에서 claude를 실행해 사용할 때는 AI가 확인하지 못할 수 있으므로, 작업 중간중간 `/context`를 입력해 사용량을 확인한다.
- 사용량이 80% 이상이면 AI에게 "남은 컨텍스트가 부족하다"고 알린다. AI는 docs/todo.md에 진행 상황을 정리하고 멈춘다.
- 이후 새 세션을 시작하면 AI가 CLAUDE.md 규칙에 따라 docs/todo.md를 읽고 이어서 작업한다.

## 자동 압축 끄기
CLAUDE.md 규칙에 따라 AI는 컨텍스트가 자동 압축되기 직전이면 작업을 멈춘다.

하지만 자동 압축은 AI가 아니라 Claude Code 프로그램이 실행하므로, AI가 압축 자체를 막을 수는 없다.

압축을 확실히 막으려면 `C:\Users\{사용자명}\.claude\settings.json` 파일에 아래 내용을 추가한다.

```json
{
  "env": {
    "DISABLE_COMPACT": "1"
  }
}
```

- 파일에 다른 설정이 이미 있다면 기존 내용은 그대로 두고 `"env"` 항목만 추가한다.
- 저장한 뒤 Claude Code를 다시 시작해야 적용된다.
- 자동 압축뿐 아니라 수동 압축(`/compact`)도 함께 꺼진다.
- 컨텍스트가 가득 차면 압축되지 않고 오류를 내며 세션이 멈춘다. 이때는 새 세션을 시작하면 AI가 CLAUDE.md 규칙에 따라 docs/todo.md를 읽고 이어서 작업한다.
